Dưới đây là danh sách các bài viết chia sẻ kỹ thuật tôi đã đăng tải trên cộng đồng AWS Study Group trong suốt thời gian thực tập:

### [Blog 1 - XÂY DỰNG ỨNG DỤNG HIỆN ĐẠI VỚI SERVERLESS ARCHITECTURE TRÊN AWS](3.1-blog-1/)
Blog này giới thiệu nội dung Khám phá cách xây dựng ứng dụng hiện đại trên AWS với kiến trúc Serverless giúp giảm quản lý hạ tầng, tự động mở rộng và tối ưu chi phí.

### [Blog 2 - XÂY DỰNG MÔI TRƯỜNG AWS AN TOÀN VỚI CLOUD SECURITY & GOVERNANCE](3.2-blog-2/)
Blog này hướng dẫn Tìm hiểu các phương pháp bảo mật và quản trị môi trường AWS thông qua IAM, Security Hub, AWS Config và các best practices.

### [Blog 3 - THIẾT KẾ KIẾN TRÚC CLOUD CHUẨN DOANH NGHIỆP VỚI AWS WELL-ARCHITECTED FRAMEWORK](3.3-blog-3/)
Blog này phân tích Khám phá cách thiết kế và đánh giá kiến trúc Cloud theo chuẩn AWS để đảm bảo hệ thống an toàn, ổn định, tối ưu và có khả năng mở rộng.
