# UPLOAD SOURCE CODE AND EXPERIENCE

## Step-by-Step Instructions:

**Step 1: Upload the file to the network**
1. Switch to the **Objects** tab.
2. Click **Upload**.
3. Select the `index.html` file (The final code version with the Delete function, multi-user capability using LocalStorage, and embedded IAM Access Keys) from your computer and upload it.

![alt text](/Workshop/images/4/4.8/image8.png)

**Step 2: Get the Link (Domain Name) and Test**
1. Switch back to the **Properties** tab.
2. Scroll to the very bottom to the **Static website hosting** section. You will see a blue link formatted like: `http://trang-web-xu-ly-anh-cua-toi.s3-website-us-east-1.amazonaws.com`.

![alt text](/Workshop/images/4/4.8/image9.png)

3. Click on this link, and the Automated Image Processing System interface will appear directly in your web browser.

![alt text](/Workshop/images/4/4.8/image10.png)
