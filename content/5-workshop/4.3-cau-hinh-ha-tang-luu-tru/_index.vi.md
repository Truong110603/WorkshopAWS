## Cấu hình hạ tầng AWS

Workshop triển khai ứng dụng trên Amazon EC2.

Các bước thực hiện:

1. Tạo VPC.
2. Tạo Public Subnet.
3. Cấu hình Internet Gateway.
4. Tạo Security Group.
5. Khởi tạo EC2 Ubuntu Server.

EC2 đóng vai trò máy chủ chạy Backend Node.js.
