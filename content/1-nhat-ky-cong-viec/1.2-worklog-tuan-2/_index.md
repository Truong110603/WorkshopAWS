## Week 2 Objectives:

* Study AWS core services including EC2, S3, and IAM.
* Practice creating an EC2 instance and connecting via SSH, managing files on S3.
* Deep dive into authorization with IAM.
* Understand AWS networking mechanisms including VPC, Subnet, and Internet Gateway.
* Practice setting up a VPC, Public/Private Subnets, Security Groups, and Network ACLs.
* Test the network connectivity of EC2 instances within the VPC.

* Mastered knowledge of EC2, S3, and IAM.
* Successfully created an EC2 instance, connected via SSH, and managed storage with S3.
