## Week 3 Objectives:

* Study database services on AWS: AWS RDS (relational) and DynamoDB (non-relational).
* Practice initializing, configuring, and connecting to a database from EC2.
* Understand the data backup and snapshot process on AWS.
* Understand Serverless architecture on AWS through the AWS Lambda service.
* Practice writing Python source code to create a Lambda Function.
* Integrate Lambda Function with S3 storage and API Gateway.
* Track and monitor Lambda logs using CloudWatch.

## Week 3 Results:

* Differentiated the characteristics and use cases of AWS RDS and DynamoDB.
* Created and configured an RDS database within a secure network partition.
* Successfully connected an application running on EC2 to the RDS database.
* Performed backup and restored data from a Snapshot to ensure data safety.
* Understood the operational mechanism, billing, and benefits of the Serverless model on AWS.
* Successfully developed Python source code running directly on Lambda without servers.
* Successfully configured a trigger from S3 and created API endpoints to invoke Lambda via HTTP.
* Mastered troubleshooting skills by querying logs on AWS CloudWatch.
