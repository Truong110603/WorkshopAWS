### Kết quả đạt được trong Tuần 2:

* Tìm hiểu về bảo mật mạng trên AWS:
  * Hiểu vai trò của Security Groups trong việc kiểm soát lưu lượng mạng.
  * Hiểu vai trò của Network ACL trong việc bảo vệ Subnet.
  * Hiểu cách giám sát lưu lượng mạng bằng VPC Flow Logs.

* Tìm hiểu và thực hành Security Groups:
  * Tìm hiểu Inbound Rules.
  * Tìm hiểu Outbound Rules.
  * Tìm hiểu các giao thức mạng phổ biến.
  * Tạo và chỉnh sửa Security Groups.
  * Cấu hình quyền truy cập SSH.
  * Cấu hình quyền truy cập HTTP.

* Tìm hiểu Network ACL:
  * Hiểu cơ chế hoạt động của Network ACL.
  * So sánh Network ACL với Security Groups.
  * Hiểu cách Network ACL kiểm soát lưu lượng ở cấp Subnet.
  * Thực hành cấu hình các Rule cho Network ACL.

* Tìm hiểu Amazon VPC Flow Logs:
  * Hiểu mục đích của VPC Flow Logs.
  * Giám sát lưu lượng mạng.
  * Thu thập thông tin về lưu lượng mạng.
  * Phân tích nhật ký lưu lượng để hỗ trợ kiểm tra và xử lý sự cố.

* Tìm hiểu DNS và Amazon Route 53:
  * Nắm được các kiến thức cơ bản về DNS.
  * Tìm hiểu các loại bản ghi DNS phổ biến.
  * Tìm hiểu Hosted Zone.
  * Hiểu cách Route 53 phân giải tên miền.
  * Thực hành cấu hình các bản ghi DNS.

* Tìm hiểu VPC Peering:
  * Hiểu khái niệm VPC Peering.
  * Tìm hiểu cách kết nối nhiều VPC.
  * Cấu hình định tuyến giữa các VPC.
  * Tìm hiểu các trường hợp sử dụng phổ biến của VPC Peering.

* Tìm hiểu AWS Lambda:
  * Hiểu khái niệm Function và Serverless.
  * Tìm hiểu cách Lambda thực thi mã mà không cần quản lý máy chủ.
  * Tìm hiểu cơ chế hoạt động và lợi ích của mô hình Serverless.
  * Tìm hiểu cơ chế tính phí của AWS Lambda.

* Thực hành AWS Lambda:
  * Tạo Lambda Function bằng Python.
  * Viết mã Python chạy trực tiếp trên Lambda.
  * Kiểm tra và thực thi Lambda Function.
  * Cấu hình trigger từ Amazon S3.
  * Tạo API endpoint để kích hoạt Lambda qua HTTP.

* Củng cố kiến thức về AWS Networking, bảo mật mạng và mô hình Serverless.

* Có thêm kinh nghiệm thực hành với VPC, Security Groups, Network ACL, VPC Flow Logs, Route 53, VPC Peering và AWS Lambda.
