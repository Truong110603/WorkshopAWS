### Week 2 Objectives:

* Learn about network security on AWS.
* Practice configuring Security Groups.
* Learn about Network ACL (NACL).
* Learn about Amazon VPC Flow Logs.
* Learn about DNS and Amazon Route 53.
* Learn about VPC Peering.
* Learn about AWS Lambda and the Serverless model.
* Practice deploying a simple Lambda function.
* Learn how to trigger Lambda functions using AWS services.
