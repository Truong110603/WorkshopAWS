### Mục tiêu Tuần 1:

* Làm quen với môi trường thực tập và các kiến thức cơ bản về AWS.
* Tìm hiểu IAM và quản lý quyền truy cập.
* Tìm hiểu cách triển khai và quản lý Amazon EC2.
* Tìm hiểu Amazon VPC và mạng trên AWS.
* Tìm hiểu cách triển khai website tĩnh bằng Amazon S3.
* Thực hành sử dụng IAM Role và AWS CLI.

### Kết quả đạt được trong Tuần 1:

* Nắm được các kiến thức cơ bản về AWS và môi trường thực tập.

* Tìm hiểu về IAM:
  * Tạo IAM Group và IAM User.
  * Gán IAM Policy.
  * Thực hành đăng nhập bằng IAM User.
  * Hiểu cách quản lý quyền truy cập bằng IAM User, IAM Role và Policy.

* Thực hành triển khai Amazon EC2:
  * Cấu hình Security Group.
  * Kết nối đến EC2 bằng SSH.
  * Cài đặt Apache.
  * Triển khai website đơn giản.
  * Tìm hiểu EC2 User Data.
  * Sử dụng User Data để tự động cài đặt Apache.
  * Triển khai website trong quá trình khởi tạo EC2.

* Tìm hiểu Amazon VPC:
  * Tạo VPC.
  * Cấu hình Public Subnet và Private Subnet.
  * Gắn Internet Gateway.
  * Cấu hình Route Table.
  * Gán Public IPv4.
  * Thực hành kết nối EC2 với VPC và kiểm tra kết nối Internet.

* Tìm hiểu Amazon S3:
  * Tạo S3 Bucket.
  * Tải các tệp website lên S3.
  * Cấu hình Bucket Policy.
  * Bật Static Website Hosting.
  * Tìm hiểu về bảo mật và quyền truy cập công khai của S3.
  * Thực hành cấu hình Block Public Access.
  * Hiểu về quyền truy cập công khai.

* Thực hành IAM Role:
  * Tạo IAM Role.
  * Gán Policy AmazonS3ReadOnlyAccess.
  * Gắn IAM Role cho EC2.
  * Truy cập Amazon S3 từ EC2 bằng AWS CLI.

* Thực hành AWS CLI:
  * Cài đặt và cấu hình AWS CLI.
  * Xác minh IAM User.
  * Liệt kê các S3 Bucket.
  * Tải tệp lên Amazon S3.
  * Thực hành truy cập S3 từ EC2.
  * Hiểu lỗi AccessDenied.
  * Tìm hiểu về IAM Deny Policy.

* Tìm hiểu Amazon RDS:
  * Tạo cơ sở dữ liệu MySQL.
  * Cấu hình Security Group.
  * Kết nối EC2 với Amazon RDS.
  * Kiểm tra kết nối cơ sở dữ liệu.

* Thực hành triển khai ứng dụng web:
  * Cài đặt Apache và PHP.
  * Kết nối PHP với Amazon RDS.
  * Truy cập ứng dụng thông qua Public IP của EC2.

* Có thêm kinh nghiệm thực hành với Amazon S3, IAM, EC2, VPC, AWS CLI và Amazon RDS.

* Nâng cao hiểu biết về quản lý quyền truy cập, mạng, máy chủ, lưu trữ và cơ sở dữ liệu trên AWS.
