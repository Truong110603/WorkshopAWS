### Kết quả đạt được Tuần 4:

* Tìm hiểu Launch Templates:
  * Hiểu AMI.
  * Hiểu Instance Type.
  * Hiểu Key Pair.
  * Hiểu Security Group.
  * Hiểu cách sử dụng Launch Templates để khởi tạo EC2.

* Tìm hiểu Elastic Load Balancer:
  * Hiểu khái niệm cân bằng tải.
  * Tìm hiểu Elastic Load Balancer (ELB).
  * Tìm hiểu Application Load Balancer (ALB).
  * Tìm hiểu Listener.
  * Tìm hiểu Target Group.
  * Tìm hiểu Routing Rules.
  * Hiểu cách phân phối lưu lượng đến các EC2.

* Tìm hiểu Auto Scaling Groups:
  * Hiểu Desired Capacity.
  * Hiểu Minimum Capacity.
  * Hiểu Maximum Capacity.
  * Tìm hiểu cơ chế tự động thay thế EC2 gặp lỗi.
  * Tìm hiểu Auto Scaling Policies.
  * Tìm hiểu Dynamic Scaling.
  * Tìm hiểu Target Tracking.

  * Hiểu trạng thái Healthy và Unhealthy.

  * Hiểu cách hệ thống phát hiện EC2 gặp lỗi.

  * Hiểu vai trò của Load Balancer trong kiến trúc Multi-AZ.
  * Hiểu cách Auto Scaling hỗ trợ khả năng sẵn sàng của hệ thống.

* Tìm hiểu kiến thức cơ bản về Docker:

  * Hiểu Docker Containers.
  * Hiểu cách tạo và chạy Container.

  * Hiểu lợi ích của Container trong triển khai ứng dụng.

* Làm quen với Amazon ECS:
  * Tìm hiểu ECS Clusters.
  * Tìm hiểu ECS Services.
  * Tìm hiểu ECS Task Definitions.
  * Hiểu kiến trúc cơ bản của Amazon ECS.
  * Hiểu cách Amazon ECS quản lý và chạy Container.
